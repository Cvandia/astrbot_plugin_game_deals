# 游戏折扣订阅 · 详细使用说明

支持 **Jump + 小黑盒同款综合比价**、Switch / Switch 2 / Steam 游戏价格查询、指定游戏订阅、每日折扣列表订阅。定时使用 **APScheduler 3.x**，数据保存到 SQLite，提供独立指令和 7 个 LLM 工具。

[返回 README](../README.md)

## 安装 / 升级

需要 Python 3.10+、AstrBot 4.13.0+、支持主动消息的平台适配器。LLM 功能还需支持工具调用的模型。

1. 升级时先禁用插件，把压缩包中的 `astrbot_plugin_game_deals` 目录覆盖到 AstrBot 的 `data/plugins/`。确认 `main.py` 直接在该插件目录内。
2. 在 **AstrBot 使用的 Python 环境**安装依赖：

   ```bash
   python -m pip install -r data/plugins/astrbot_plugin_game_deals/requirements.txt
   ```

3. 重载插件或重启 AstrBot。Docker 部署须在对应容器环境安装依赖。
4. 需要自然语言功能时，在 AstrBot 工具管理 / 当前 Agent 工具组开放本插件的 7 个工具。

旧版单游戏订阅和通知时间保留。新增日报表采用 `CREATE TABLE IF NOT EXISTS`，不删除原表。数据库位于 `data/plugin_data/astrbot_plugin_game_deals/subscriptions.sqlite3`，升级前可备份该文件及其 WAL 文件，或停机后备份整个插件数据目录。

## 独立指令

无需所有操作都写在 `/游戏折扣` 后面。旧入口继续兼容，发送 `/游戏折扣` 可查看帮助。

| 指令 | 示例 |
| --- | --- |
| 综合比价 | `/游戏比价 马车8` |
| 查价（名称自动综合比价，ID查单来源） | `/游戏查价 马车8`、`/游戏查价 jump:294` |
| 搜索指定来源 | `/游戏搜索 switch 马力欧卡丁车8` |
| 搜索 Switch 2 | `/游戏搜索 jump 马力欧` |
| 搜索小黑盒目录 | `/游戏搜索 heybox 马里奥赛车8` |
| 今日折扣 | `/今日折扣 jump 5`、`/今日折扣 heybox 5` |
| 订阅单款游戏 | `/订阅游戏 jump:294`、`/订阅游戏 heybox:900000090` |
| 退订单款 | `/退订游戏 jump:294` |
| 单游戏订阅列表 | `/游戏订阅列表` |
| 立即检查单游戏订阅 | `/检查游戏折扣` |
| 单游戏检查时间 | `/折扣通知时间 20:30` |
| 暂停 / 恢复单游戏通知 | `/暂停游戏通知`、`/恢复游戏通知` |
| 每日折扣列表订阅 | `/订阅折扣日报 20:30 jump 5` |
| 多来源日报订阅 | `/订阅折扣日报 20:30 all 5` |
| 退订某来源日报 | `/退订折扣日报 jump` |
| 日报列表 | `/折扣日报列表` |
| 日报图片 / 文字样式 | `/折扣日报样式 image jump`、`/折扣日报样式 文字 all` |
| 暂停 / 恢复日报 | `/暂停折扣日报 all`、`/恢复折扣日报 all` |

命令前缀和群内是否需要 @ 机器人遵循 AstrBot 的唤醒配置。

来源参数：

| 参数 | 内容 |
| --- | --- |
| `jump` / `switch2` | Jump 中明确标记的 Switch 2 游戏本体 |
| `switch` | Jump 中明确标记的 Switch 初代游戏本体 |
| `heybox` | 小黑盒 Switch 系列，来源未细分代际时会明确标注 |
| `steam` | Steam 商店游戏 |
| `all` | 仅用于日报管理，对四个来源分别订阅/操作，每个来源各一条日报 |

日报订阅格式为 `HH:MM [来源] [数量1-20] [image|text|default]`，来源默认 `jump`、数量默认 5。退订、暂停和恢复日报的来源默认也是 `jump`，要操作全部来源需显式使用 `all`。

ID 使用搜索结果中的完整标识：Jump 为 `jump:数字`（旧 `oldGameId`），小黑盒为 `heybox:数字`，Steam 为 `steam:AppID`。保留旧数据库裸数字 Steam ID 的解释。命令中的裸数字按所选来源解析，LLM 工具强制带来源 ID，避免混用。

## “马车8”如何综合比价

`/游戏比价 马车8` 或 `/游戏查价 马车8` 会查询：

- Jump：`jump:294`，Switch《马力欧卡丁车8 豪华版》。
- 小黑盒：`heybox:900000090`，《马里奥赛车8 豪华版》。

这两个条目已经通过真实目录和详情核对。每次仍校验返回 ID、完整版本名称及 Jump 平台，不能把《马力欧卡丁车：世界》、DLC、升级包或组合包误当作相同版本。

结果保留来源、地区、平台、折扣幅度、链接和查询时间。Jump 和小黑盒展示的是**各自提供的跨区人民币折算参考价**；支持在币种及版本可比较时指出本次已取得报价中的较低参考值，不称为“全网最低价”。不同地区有账号购买资格、语言和实时汇率差异。两个信息来源也可能引用同一个 eShop，并不代表两个独立销售渠道。

其他名称会在 Jump 和小黑盒中搜索，要求规范化后的精确名称唯一匹配；马力欧/马里奥、卡丁车/赛车的常见写法会统一。找到多个版本时返回候选，要求更精确的名称。平台代际未能核实时只并列展示，不计算跨来源最低价。一个来源失败时保留另一个来源的报价并明确标注缺失，绝不把失败当成无折扣。

当前综合比价针对 Jump 与小黑盒 Nintendo 数字版本体；没有把实体卡、账号租赁、商城券后价、会员专享价混进来。Steam 保留独立查询与订阅，不拿 PC 价格直接排名为 Switch 的购买最低价。

## 每日折扣列表订阅

日报不需要先添加任何单游戏订阅，与单款游戏的“有折扣才通知”独立。

```text
/订阅折扣日报 09:00 jump 5
/订阅折扣日报 20:30 switch 10
/订阅折扣日报 20:30 heybox 5
/折扣日报列表
```

- 每个会话、每个来源各一条订阅，可以设置不同时间和数量；重复订阅会更新时间、数量并启用。
- 到点查询该来源的当前折扣，推送最多指定数量；范围内暂无优惠也会发送“本次扫描范围内暂无”的日报。
- 每个来源当天成功完成后不再重复。源查询失败或消息失败至少间隔 5 分钟重试。
- 内容较长时分段推送；分段内容和已发送状态保存到数据库。重启后只重试未成功的分段。
- 同一天退订后再订阅不会重复已成功发送的日报。修改数量/时间不重发已成功内容；已生成但未完成的日报继续使用原快照，避免重试时内容漂移。
- 暂停保留设置，恢复后若已过当天时间会补发尚未完成的日报。
- 只补查当天，不补发过去数日。`all` 按来源分别推送，来源失败互不阻塞，可能展示同一游戏的不同来源记录。

`/暂停游戏通知` 只影响单款游戏提醒，`/暂停折扣日报` 只影响日报。

## 图片日报：参考新闻长图模板

图片采用米白底色、橙色点缀、左侧大标题和日期、右侧大星期、编号游戏列表、页脚寄语及来源说明。价格用橙色突出，保留游戏名称、平台、地区、完整ID、币种折算标记，以及来源提供的截止时间。只使用真实折扣数据，不加入新闻内容、无法核实的农历日期或其他人的署名。

**全局切换：** 在插件配置中把 `digest_send_mode` 设为 `image` 并重载。既有订阅默认跟随全局配置；默认值仍为 `text`，升级后不会自动改成图片。

**为当前会话、当前来源单独选择：**

```text
/订阅折扣日报 20:30 jump 5 image
/折扣日报样式 图片 jump
/折扣日报样式 text jump
/折扣日报样式 default all
/折扣日报列表
```

`image` / `图片` 为图片，`text` / `文字` 为文字，`default` / `默认` 跟随全局。样式指令只修改已有日报订阅，不会创建新订阅。群内修改样式仍需 AstrBot 管理员，私聊用户可自行修改。单游戏折扣提醒继续使用文字。

图片默认每页最多8款，可设置1–10款；超过时自动分页，连续编号。空结果也会生成一页“扫描范围内暂无折扣”的日报。超长名称自动换行，超过图片布局范围时使用省略号，完整文字仍保留在日报快照中。

图片通过 **Pillow 在本地生成**，用 AstrBot `MessageChain.file_image` 发送，不依赖浏览器、外部截图服务或运行时字体下载。插件自带 Noto Sans SC 中文字体（© 2014-2021 Adobe，SIL OFL 1.1），声明位于 `licenses/NotoSansSC-OFL.txt`。可用 `digest_font_path` 指定部署机器上可读的中文字体文件。

渲染结果缓存于插件数据目录的 `digest_images/`，文件名使用快照哈希，不含群号或用户ID。生成新图片时清理超过7天的旧缓存，字体和数据库不会被清理。图片页的实际数据快照、页码及发送检查点保存到 SQLite，重启不会重新查询已生成日报或重复已成功页。

`digest_image_fallback=true` 时，字体、渲染或图片投递失败会尝试文字回退；长文字继续分段并记录已发进度。关闭此项后，图片失败按原有5分钟退避重试。平台实际发出消息后却报错，仍可能造成图片与回退文字同时出现，属于既有投递确认边界。

切换样式不会重发当日已完成日报，也不会改写当日已生成的待发快照；下一次新生成日报使用新样式。

生成本地真实数据预览（不订阅、不发送聊天消息）：

```bash
python preview_digest.py
```

脚本只读访问 Jump，将图片输出到插件目录同级的 `game_deals_preview/`，终端会显示绝对路径。

## 权限与会话

群聊订阅发到当前群，私聊订阅发到本人当前私聊；没有可由 LLM 填入的目标群号/用户 ID/管理员标记。

| 操作 | 群聊权限 |
| --- | --- |
| 查询、搜索、综合比价、查看订阅 | 所有可调用命令的用户 |
| 添加单游戏订阅 | 所有可调用命令的用户 |
| 删除单游戏订阅 | 创建者或 AstrBot 管理员 |
| 单游戏时间、暂停、恢复 | AstrBot 管理员 |
| 日报订阅/修改/退订/暂停/恢复 | AstrBot 管理员 |

私聊用户可自行管理当前会话。AstrBot 管理员不是聊天平台群管理员角色。

## LLM 工具

| 工具 | 用途 |
| --- | --- |
| `game_deals_search` | 指定来源搜索版本与完整 ID |
| `game_deals_today` | 查询当前扫描范围内折扣 |
| `game_deals_price` | 按 ID 查询单来源价格 |
| `game_deals_compare` | 按名称/别名综合比价，例如马车8 |
| `game_deals_subscriptions` | subscribe/unsubscribe/list/check 单游戏订阅 |
| `game_deals_schedule` | set_time/pause/resume 单游戏检查设置 |
| `game_deals_daily_digest` | subscribe/unsubscribe/list/pause/resume 日报订阅，set_mode 修改发送样式 |

新增日报工具参数：

```json
{"action":"subscribe","source":"jump","time":"20:30","limit":5,"mode":"image"}
```

`mode` 支持 `image/text/default`，默认跟随全局；`action=set_mode` 可只改样式。

`source` 支持 `jump/switch/heybox/steam/all`；时间留空使用插件默认时间。时区默认北京时间，按插件 `timezone` 配置执行。

自然语言示例：

```text
马车8现在多少钱？综合对比Jump和小黑盒。
每天晚上八点半，给这个群用图片推送5款Switch 2折扣游戏。
每天上午九点推送小黑盒的当前折扣。
看看这个会话订阅了哪些日报。
停止这个会话所有来源的每日折扣推送。
```

工具返回 JSON 字符串，成功为 `{"ok":true,"result":"..."}`，失败为 `{"ok":false,"error":"..."}`。自然语言询价引导模型优先使用比价工具；模型实际是否调用由当前 Agent 决定。修改订阅仅应按用户明确意图执行，查价不会自动订阅。权限与指令完全共用。即时结果由模型组织回复，定时推送仍由插件主动发送。

## 数据来源与范围

**Jump** 使用公开可匿名读取的应用接口，搜索 `/jump/searchGame/list/v2`、折扣列表 `/jump/discount/find4Discount/5/v2`、详情 `/jump/game/detail`。搜索每页 30 项，折扣每页 10 项，默认扫描最多 5 页。`platform=1,subPlatform=10/11` 分别区分 Switch / Switch 2，列表接口忽略平台子类型时由插件本地过滤。明确标注的 DLC/升级包排除。列表金额为人民币元，详情金额为人民币分，分别转换；不使用会员 `plusPrice` 或商城促销标记判断降价。

**小黑盒** 已核验匿名可用的目录 `/game/get_game_list_v3/`、基础价格 `/game/get_game_infos/`、主机详情 `/game/console/get_game_detail/`，域名 `api.xiaoheihe.cn`。关键词搜索接口实际返回要求登录，因此当前使用 **有限目录本地检索**，默认最多 5 页、每页 30 款，缓存 5 分钟，不声称全站搜索。已知 ID 查询直接读取详情和价格，不依赖是否在目录中出现。未登录搜索不到不代表游戏不存在。

小黑盒 `platform_infos.key=switch` / `platforms_list.platf=switch` 不足以单独确认 Switch 2 代际，通常展示“来源未细分代际”；马车8使用核验过的精确版本映射。仅采用返回的游戏数字版价格及地区，不采用 `heybox_price` 优惠券/会员条件。人民币小数通过 Decimal 转分。请求使用公开 Web URL 校验算法，无需用户 Cookie 或账号。算法移植自 [huandu/heybox-url](https://github.com/huandu/heybox-url)，保留 MIT 声明于 `licenses/heybox-url-MIT.txt`。

**Steam** 使用商店公开接口，地区默认 `cn`。当前折扣为精选列表。

所有来源的“今日”都表示**当前扫描范围内的优惠**，不是今日新开始，也不是全站完整清单。单款游戏的每日检查直接按 ID 请求，不受列表范围限制。接口限流、字段变化、要求登录或网络失败会明确报错并重试，不自动登录或绕过验证。

## 调度与配置

APScheduler `AsyncIOScheduler` 每 30 秒触发一次到期记录检查，启用 `coalesce=True`、`max_instances=1`、`misfire_grace_time=300`。启动立即补查当天到期记录，卸载时取消执行中的检查并关闭资源。任务使用内存 job store，订阅、快照及去重状态使用 SQLite；不序列化插件实例到 scheduler。大量游戏或网络慢时会顺延。

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `default_source` | `jump` | 命令默认来源：jump/switch/heybox/steam |
| `timezone` | `Asia/Shanghai` | 时区，默认北京时间 |
| `default_time` | `09:00` | 新会话单游戏时间及未指定时间的日报默认值 |
| `jump_max_pages` | `5` | Jump 搜索/列表每次扫描页数，1–20 |
| `heybox_max_pages` | `5` | 小黑盒目录扫描页数，1–20 |
| `country` | `cn` | 仅影响 Steam 地区 |
| `max_subscriptions` | `50` | 每会话单游戏上限，1–200，不影响每来源一条的日报 |
| `request_timeout` | `20` | 每次请求超时秒数，5–60 |
| `digest_send_mode` | `text` | 日报全局样式，text 或 image |
| `digest_image_fallback` | `true` | 图片生成/发送失败时回退文字 |
| `digest_image_rows` | `8` | 每页最多游戏数，1–10 |
| `digest_font_path` | 空 | 留空使用插件自带中文字体 |

全局修改后重载插件。依赖 `APScheduler>=3.10.4,<4`，不要替换为不兼容的 4.x 预览版。

## 验证与投递边界

```bash
python -m unittest discover -s tests -q
python smoke_test.py
python smoke_test.py --source steam
python smoke_compare.py
```

`smoke_compare.py` 会真实只读查询 Jump 和小黑盒马车8报价、小黑盒目录和当前折扣，结果随时间变化。自动测试验证金额、平台、版本、别名、权限、失败处理、独立指令、工具、日报分段及重启去重。

完整 AstrBot 加载、实际模型选择工具和群聊/私聊投递，仍需在你的实例验证。主动消息使用 `Context.send_message`，适配器必须支持；AstrBot 上游注明 QQ 官方 API 平台不支持此发送方式。

发送后写库前崩溃，或平台实际投递后返回错误，仍可能导致重试重复。分段检查点和每日去重降低重复，但不承诺严格一次投递。价格以商店实时结算为准。
